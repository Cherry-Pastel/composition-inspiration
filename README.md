# 作文靈感補給站｜GitHub Pages 版

這是一個純前端靜態網站，依照使用者提供的視覺參考，採用暖白、奶油米、陶土橘、鼠尾草綠與襯線標題。網站主要動線是：**選年度 → 看該年度題目與寫作要求 → 閱讀優秀範文 → 在同一篇文章下方閱讀分析**。本版本不再以關鍵字素材搜尋作為首頁主要功能。

## 網站內容

- 108–115 年學測國寫共 87 篇整理：知性題 43 篇、情意題 44 篇。
- 依年度（108–115）切換，並可選擇全部年度。
- 各年度分為知性題與情意題，先呈現題目材料／引文、作答要求與大考中心來源，再列出該題優秀範文。
- 展開單篇範文後，先顯示範文原文，接續呈現分析：
  - 知性題：四部分大綱、素材與論證用途、論證／思考亮點、原文佳句、核心洞見、可遷移寫作策略。
  - 情意題：四部分大綱、寫作亮點、原文佳句、寫作技巧與效果、核心洞見、可遷移寫作策略。
- 四部分大綱以心智圖呈現：中心顯示核心主旨，四條分支依序標示 01–04，呈現各部分大綱；手機版改為縱向分支排列。
- 每篇範文提供大考中心官方來源連結；若題目涉及圖表或圖像，會提示讀者以官方原卷為準。
- 響應式版面，支援電腦與手機。

## 本機預覽

本版本將資料以 `data/essays.js` 載入，因此可以直接雙擊 `index.html` 預覽，不必先啟動本機伺服器。也可以在專案資料夾執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。

`data/essays.json` 是便於資料整理與檢核的 JSON 主檔；`data/essays.js` 是供網頁直接載入的版本。若更新 `essays.json`，請在專案資料夾執行 `python sync_data.py` 產生最新的 `essays.js`，再一起上傳兩個檔案。

## 發布到 GitHub Pages（不需要 Netlify）

1. 在 GitHub 建立 repository，例如 `composition-inspiration`。
2. 將本專案資料夾內的檔案上傳至 repository 根目錄，確認 `index.html`、`styles.css`、`app.js`、`data/essays.json` 與 `assets/tree-mark.svg` 均在正確位置。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 Build and deployment 區域，將 Source 選為 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`，再按 Save。
5. 等待 GitHub Pages 部署完成，依畫面提供的網址測試各年度題目、展開範文、分析與官方來源連結。
6. 後續更新時，將更新後的檔案 commit 到同一個 repository，即可觸發重新發布。

## 資料來源與使用提醒

範文與題目資料根據使用者提供、整理自大學入學考試中心（大考中心）公布的學測國寫資料。網站提供逐篇官方來源連結，並註明本站為非官方教學整理、與大考中心無隸屬關係。**來源標示本身不等於取得全文重製或公開傳輸授權。** 正式公開前，請確認完整範文、題目引文與其他材料的使用條件；若未能確認，請先移除全文或改成短摘錄加官方原卷連結。

## 閱讀版面調整

- 每篇範文依原文換行切分成獨立段落，各段段首統一空兩個中文字元（`text-indent: 2em`）。
- 分析區正文統一提高至 15px，佳句採略大字級以保留視覺層次，手機版同樣維持可讀字級。

## 題目與引文閱讀版面調整

- 題目作答要求與展開的題目材料／引文統一為 14px。
- 題目與引文每一個獨立段落首行統一縮排兩個中文字元（`text-indent: 2em`）。
- 桌面與手機版皆維持 14px，並以約 1.9–1.95 倍行高改善長文閱讀。
